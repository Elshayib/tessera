## What to build

A Person can start a Scene, type Intent, and receive Narration. A scripted Provider places one named Object and Frames it. No live window. No live Key. This is the loop existing: Intent in, something named in the Scene, the Agent saying what it did.

## Acceptance criteria

- [ ] A test acting as the Person starts a Scene with no account and types Intent.
- [ ] A scripted Provider (not a live lab) places one named Object and Frames it.
- [ ] Narration says what happened and uses the Object's name.
- [ ] The Person never names a Verb.
- [ ] Tests do not open a real window and do not call a live Provider.
- [ ] Tessera is MIT-licensed in the repo.
