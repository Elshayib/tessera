# The Scene is the document

The Person makes a Scene — a place — not a single Object on a studio turntable, and not a Shot. Dusk lighting and camera framing are Scene-level Verbs; they do not make the framed view the working document. A one-object studio was rejected because the product's own example (a lighthouse on a cliff at dusk) is a place. Treating the Shot as the document was rejected because that is a film tool, and the Person must still be able to Orbit the place.
