# A Key belongs to a short list of Providers

v1 the Person pastes a Key for one of a short list of paid APIs. Tessera's Verbs and system prompt stay the same when the Provider changes. That is how "weaker models can still do good work" gets tested.

One Provider was rejected: Tessera would become a skin of that lab. Any model including local was rejected for v1: that is support hell, and local models are a later door, not the thing v1 is debugged against.

Superseded in part by ADR-0021: the short list includes gateways, and the Person picks a Brain from a live catalog. Local and a generic URL remain out.
