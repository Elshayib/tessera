# Guess and move; Ask only when Undo cannot cheaply save them

The Agent Guesses, names the guess in Narration, and keeps the Viewport moving. It Asks only when the next Verb would be hard to Undo: deleting, a big Sculpt, or two Objects that could match and Point was not used.

Always-guess was rejected: "the other roof" becomes a ruined Mark they did not know they needed. Always-ask was rejected: the Viewport sitting still is a form, not the watching product.
