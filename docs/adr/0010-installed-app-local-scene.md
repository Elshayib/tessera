# Tessera is an installed app; the Scene is a local file

The Viewport is the product, so the Engine runs on the Person's machine. v1 is an installed app. The Scene is a file on disk. No account is required to make one. The Key is only for the Agent's brain.

A browser product was rejected: the Engine would have to fit a browser GPU, and Clay + a dense Scene will not, for a while. A cloud Engine with a streamed Viewport was rejected: it puts a network between the Person and the work, and Tessera would pay for 3D compute while inference is already bring-your-own-key. A web demo can exist later as marketing. It is not v1.

v1 ships on Windows. Mac and Linux are later. The Engine must not be written so those are a rewrite.
