# The Viewport is the product

The Person watches Verbs land in a live 3D Viewport. That watching loop is the product. v1 also has chat and Narration so the Person can follow what the Agent is doing ("why did it flatten the roof?").

A chat-with-pictures path was rejected: that is every image-to-3D site, and it is not "see the Agent working." A silent Viewport with no Narration was rejected for v1 because a beginner loses the plot.
